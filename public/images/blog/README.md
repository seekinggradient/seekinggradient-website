# Editorial image prompts

## `hermes-editorial-memory-architecture.png`

Use case: editorial hero image. Create a cinematic, photorealistic research workspace at night for an essay about durable memory in personal AI agents. Show a dark desk, closed notebook, pencil, laptop keyboard, and a monitor with subtle lines of code. Project several translucent handwritten note pages and a quiet grid onto the wall beside the monitor to suggest memory layers moving from human notes into software. Use low-key teal-black shadows, a warm amber pool of light, fine film grain, and generous negative space. The mood should feel thoughtful, investigative, and technically serious rather than futuristic or promotional. Wide 3:2 composition. No people, no logos, no readable private information, no robot imagery, no holographic UI panels, no watermark.
